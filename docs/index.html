How It Works

Comparison

FastQC vs ampliQC

Generic FastQC / Falco

WGS Assumptions
  • False Duplication Warnings: Flags high duplication rates (>50%) as errors, ignoring amplicon locus targeting.
  • False Base Composition Failures: Flags non-uniform A/C/G/T at read starts caused by fixed PCR primers.
  • No Trimming Guidance: Fails to detect degenerate IUPAC primers or generate Cutadapt/DADA2 parameters.

ampliQC Engine

Amplicon-Aware
  • Biological Duplication PASS: Correctly validates expected sequence duplication in 16S/18S/ITS locus amplicons.
  • Positional Terminal Scanning: Detects 5' and 3' PCR primers with zero internal gene body false positives.
  • Actionable Trimming Commands: Generates ready-to-copy Cutadapt CLI commands and DADA2 `truncLen` parameters.
Capabilities

Key Features

Multi-Target Biological Profiling

Supports 16S (V1-V3, V3-V4, V4, V9, Full-Length), 18S, ITS, COI, 12S MiFish, rbcL, matK, nifH, and amoA.

Cutadapt Command Generator

Produces exact CLI commands for Cutadapt & Chopper containing detected forward and reverse primers.

DADA2 `truncLen` Calculator

Calculates optimal DADA2 truncation lengths maintaining required read overlap for ASV merging.

Parallel Batch Engine

`ampliqc run-batch` processes entire directories of FASTQ files using multi-core process pools.

MultiQC & TSV Exports

Outputs native MultiQC JSON custom data modules (`_ampliqc_mqc.json`) and summary TSV matrices.

Docker & Apptainer Containers

Includes Dockerfile and Apptainer manifests for reproducible execution in HPC & Cloud environments.

CLI & API

Usage & Examples

Illumina 16S V3-V4 Analysis

# Single sample paired-end run with automatic context detection
ampliqc run -1 sample_R1.fastq.gz -2 sample_R2.fastq.gz --context auto -o qc_output/

# Explicit context profile setting
ampliqc run -1 sample_R1.fastq.gz -2 sample_R2.fastq.gz --context amplicon_16s -o qc_output/

Full-Length ONT & PacBio HiFi Analysis

# Oxford Nanopore Full-Length 16S (~1,500 bp)
ampliqc run -1 sample_ont_16s.fastq.gz --context ont -o qc_output/

# PacBio HiFi Full-Length 16S
ampliqc run -1 sample_pacbio.fastq.gz --context pacbio_hifi -o qc_output/

Custom IUPAC Primers & Database

# Specify custom forward & reverse primers directly
ampliqc run -1 sample_R1.fastq.gz -2 sample_R2.fastq.gz \
  --primer-f GTGYCAGCMGCCGCGGTAA \
  --primer-r GGACTACNVGGGTWTCTAAT \
  -o qc_output/

# Load custom YAML primer database file
ampliqc run -1 sample_R1.fastq.gz -2 sample_R2.fastq.gz \
  --primer-db my_lab_primers.yaml \
  -o qc_output/

Parallel Multi-Sample Batch Engine

# Run multi-sample batch processing across a directory (8 threads)
ampliqc run-batch -i /path/to/fastq_directory/ -o batch_qc_results/ -t 8

Python Programmatic API

from ampliqc.core.parser import read_fastq
from ampliqc.core.stats import FastqStatsAccumulator
from ampliqc.context.amplicon import AmpliconContextAnalyzer

accumulator = FastqStatsAccumulator()
sequences = []

for record in read_fastq("sample.fastq.gz"):
    accumulator.process_record(record)
    if len(sequences) < 50000:
        sequences.append(record.sequence)

stats_summary = accumulator.get_summary()
analyzer = AmpliconContextAnalyzer(target_region="amplicon_16s")
eval_results = analyzer.evaluate(stats_summary, sample_sequences=sequences)

print("Target Region:", eval_results["metadata"]["target_region"])
print("Trimming Status:", eval_results["metadata"]["trimming_status"])
