Why Generic QC Tools Fail for Amplicon Libraries

FastQC and Falco evaluate reads against random Whole Genome Sequencing (WGS) assumptions, triggering false-positive warnings for expected biological features of PCR amplicons.

Generic Tools (FastQC / Falco)

False Warnings
  • Sequence Duplication Failure Flags high duplication (>50%) as library bottleneck or PCR duplication error, ignoring that amplicon target loci inherently produce identical reads.
  • Per-Base Sequence Content Failure Flags non-uniform A/C/G/T ratio at read starts, ignoring that reads begin at fixed PCR primer binding sites.
  • Blind to PCR Primers & Trimming Does not detect IUPAC degenerate primers (e.g. 341F / 805R / 515F) or calculate downstream ASV/OTU impact.

ampliQC Engine

Context-Aware
  • Biological Duplication PASS Recognizes high locus duplication as an expected biological feature of targeted marker genes (16S, 18S, ITS).
  • Positional Terminal Primer Anchoring Scans 5' and 3' terminal extremities for PCR primers (IUPAC codes) with zero false-positive internal gene body hits.
  • Cutadapt & DADA2 Parameter Generator Generates ready-to-copy Cutadapt CLI commands and optimal DADA2/QIIME 2 truncation lengths (`truncLen`).

Pipeline Architecture & Execution Flow

From raw FASTQ reads to context-aware biological metrics and MultiQC-ready outputs.

1

FASTQ Streaming

Low-memory streaming parser for Short & Long Reads (.fastq.gz).

2

Context Auto-Detect

Profiles target region (16S V3-V4, V4, ITS, 18S, ONT, PacBio).

3

Terminal Primer Scan

Positional 5' and 3' IUPAC regex scanning and trimming status.

4

Biological Evaluation

Re-evaluates duplication, base bias, quality decay & DADA2 parameters.

5

Multi-Format Reports

Generates HTML, JSON, YAML, MultiQC JSON & PNG figures.

Key Features & Capabilities

Engineered for bioinformaticians, sequencing core facilities, and microbiome researchers.

Multi-Target Biological Engine

Built-in support for 16S (V1-V3, V3-V4, V4, V9, Full-Length), 18S, ITS, COI, 12S MiFish, rbcL, matK, nifH, and amoA targets.

Automated Trimming Commands

Generates exact ready-to-copy Cutadapt and Chopper CLI commands containing detected forward and reverse primers.

DADA2 / QIIME 2 Optimization

Calculates exact truncation lengths (`truncLen` R1/R2) based on Phred score decay ensuring sufficient read overlap.

Parallel Multi-Sample Engine

`ampliqc run-batch` processes entire directories of FASTQ files using multi-core CPU process pools.

MultiQC & TSV Exports

Outputs native MultiQC custom data files (`_ampliqc_mqc.json`) and consolidated TSV summary matrices.

Docker & Apptainer HPC Ready

Includes Dockerfile and Apptainer/Singularity manifests for 100% deterministic workflow execution on HPC clusters.

Usage & Examples

Explore CLI commands and Python API usage patterns.

Paired-End Illumina 16S V3-V4 Analysis

Automatic context detection and Quality Control for short-read amplicon libraries.

# Single sample paired-end run with automatic context detection
ampliqc run -1 sample_R1.fastq.gz -2 sample_R2.fastq.gz --context auto -o qc_output/

# Explicit context profile setting
ampliqc run -1 sample_R1.fastq.gz -2 sample_R2.fastq.gz --context amplicon_16s -o qc_output/

Full-Length Long-Read Amplicon Analysis

Analyze Oxford Nanopore and PacBio HiFi full-length 16S / ITS reads.

# Oxford Nanopore Full-Length 16S (~1,500 bp)
ampliqc run -1 sample_ont_16s.fastq.gz --context ont -o qc_output/

# PacBio HiFi Full-Length 16S
ampliqc run -1 sample_pacbio.fastq.gz --context pacbio_hifi -o qc_output/

Custom IUPAC Primers & Custom Database

Specify lab custom primer sequences or load custom YAML databases.

# Specify custom forward & reverse primers directly
ampliqc run -1 sample_R1.fastq.gz -2 sample_R2.fastq.gz \
  --primer-f GTGYCAGCMGCCGCGGTAA \
  --primer-r GGACTACNVGGGTWTCTAAT \
  -o qc_output/

# Load custom YAML primer database file
ampliqc run -1 sample_R1.fastq.gz -2 sample_R2.fastq.gz \
  --primer-db my_lab_primers.yaml \
  -o qc_output/

Multi-Sample Parallel Batch Engine

Process hundreds of samples in parallel with CPU process pools.

# Run multi-sample batch processing across a directory (8 threads)
ampliqc run-batch -i /path/to/fastq_directory/ -o batch_qc_results/ -t 8

Python Programmatic API

Integrate ampliQC directly into Python workflows and pipelines.

from ampliqc.core.parser import read_fastq
from ampliqc.core.stats import FastqStatsAccumulator
from ampliqc.context.amplicon import AmpliconContextAnalyzer

accumulator = FastqStatsAccumulator()
sequences = []

for record in read_fastq("sample.fastq.gz"):
    accumulator.process_record(record)
    if len(sequences) < 50000:
        sequences.append(record.sequence)

stats_summary = accumulator.get_summary()
analyzer = AmpliconContextAnalyzer(target_region="amplicon_16s")
eval_results = analyzer.evaluate(stats_summary, sample_sequences=sequences)

print("Target Region:", eval_results["metadata"]["target_region"])
print("Trimming Status:", eval_results["metadata"]["trimming_status"])
